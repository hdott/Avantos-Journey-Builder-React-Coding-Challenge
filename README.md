To run the mock server, first open a terminal in frontendchallengeserver & run
  npm start

To run the application, in another terminal, open my-app & run
  npm start

When prompted with 

"Something is already running on port 3000
Would you like to run the app on another port instead?",

enter Y



If you wish to change the url being fetched from, edit baseUrl in src/features/flow/flowAPI,js
(Note that this also means you wouldn't have run the mock server)
